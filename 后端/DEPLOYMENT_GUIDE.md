# WildAPI 部署指南（宝塔面板 · 菜单式操作）

> **部署体验**：全程只需编辑一次 `.env` 配置文件 + 运行一个脚本，
> 之后所有管理操作（部署/启停/日志/备份）都在**菜单面板**中选择数字完成，
> 无需记忆任何 Docker 命令。

---

## 一、环境准备（宝塔面板操作，约 2 分钟）

### 1.1 安装 Docker

1. 登录宝塔面板
2. 左侧菜单 → **软件商店**
3. 搜索 **Docker** → 安装 **Docker 管理器**（会自动安装 Docker 和 Compose）

### 1.2 上传项目

1. 宝塔面板 → **文件**
2. 进入 `/opt/` 目录（没有就新建）
3. 上传 `WildAPI.tar.gz`
4. 右键压缩包 → **解压**，得到 `/opt/WildAPI/后端` 和 `/opt/WildAPI/前端`

> 最终目录结构必须是：`/opt/WildAPI/后端`、`/opt/WildAPI/前端` 并列。

---

## 二、配置（唯一需要手动编辑的步骤）

1. 宝塔面板 → **文件** → `/opt/WildAPI/后端/docker/`
2. 双击 `.env` 文件在线编辑，确认以下内容：

| 配置项 | 说明 | 建议 |
|-------|------|------|
| `MYSQL_ROOT_PASSWORD` | MySQL root 密码 | 保持强密码 |
| `MYSQL_PASSWORD` | MySQL 业务账号密码 | 保持强密码 |
| `REDIS_PASSWORD` | Redis 密码 | 保持强密码 |
| `JWT_SECRET` | 登录会话密钥 | 勿更换 |
| `ENCRYPTION_KEY` | 数据加密密钥 | **生成后永不可更换** |
| `SSO_CLIENT_SECRET` | WildAccount 凭据 | 勿更换 |
| `FRONTEND_PORT` | 前端端口 | 80 被宝塔占用时用 `3002` |
| `BACKEND_PORT` | 后端端口 | 3000 被占用时用 `3001` |

> **数据包里不再附带 `.env`**（之前那份把真实密码、`ENCRYPTION_KEY`、`SSO_CLIENT_SECRET`
> 一起打包了，等于凭据随包扩散）。首次部署先复制模板再填写：
>
> ```bash
> cd /opt/WildAPI/后端/docker && cp .env.example .env   # 或直接跑 ./deploy.sh，缺 .env 时会引导你复制
> ```
>
> `<REQUIRED: ...>` 占位符必须全部替换，否则 `validateConfig()` 会拒绝启动。
> `ENCRYPTION_KEY` 一旦有密钥入库就**永不可更换**（换了就解不开已存的厂商密钥）。

---

## 三、一键部署（菜单式）

### 3.1 打开管理面板

宝塔面板 → **终端**（或用 SSH 工具连接服务器），执行：

```bash
cd /opt/WildAPI/后端/docker
chmod +x wildapi.sh deploy.sh uninstall.sh
./wildapi.sh
```

### 3.2 选择部署

看到菜单后，输入 **1** 回车：

```
╔══════════════════════════════════════════╗
║      WildAPI - Docker 管理面板           ║
╚══════════════════════════════════════════╝

  1) 一键部署 / 更新      (构建镜像并启动全部服务)
  2) 查看服务状态        (容器状态 + 访问地址)
  3) 启动服务
  4) 停止服务            (数据保留)
  5) 重启服务
  6) 查看实时日志
  7) 备份数据库          (导出到 /opt/WildAPI/backups)
  8) 完全卸载

  0) 退出

  请输入选项 [0-8]: 1
```

脚本自动完成：创建数据目录 → 构建镜像 → 启动服务 → 执行数据库迁移。
首次部署约 3-5 分钟。

### 3.3 验证

部署完成后，菜单选 **2** 查看状态，然后浏览器访问：

- **前端面板**：`http://服务器IP:3002`（或你配置的端口）
- 用 WildAccount 登录，确认能进入面板

## 四、日常管理（全部菜单操作）

随时运行 `./wildapi.sh` 打开菜单：

| 想做什么 | 菜单选项 |
|---------|---------|
| 看服务是否正常运行 | **2** 查看服务状态 |
| 服务挂了想重启 | **5** 重启服务 |
| 排查问题看日志 | **6** 查看实时日志（再选后端/前端/MySQL/Redis） |
| 升级前备份 | **7** 备份数据库 |
| 更新代码后重新部署 | **1** 一键部署 / 更新 |
| 临时停用 | **4** 停止服务 |

> 日志页面按 `Ctrl + C` 退出，自动返回菜单。

---

## 五、宝塔图形化管理（可选）

除菜单面板外，也可用宝塔的图形界面：

1. 宝塔面板 → **Docker 管理器**
2. **容器** 标签页可看到 4 个容器：
   - `wildapi-mysql`（数据库）
   - `wildapi-redis`（缓存）
   - `wildapi-backend`(API 后端)
   - `wildapi-frontend`（前端）
3. 每个容器右侧按钮可直接 **启动/停止/重启/日志**

> 注意：宝塔界面适合日常启停和看日志；**首次部署和版本更新请用菜单 [1]**，
> 因为它会自动执行数据库迁移。

---

## 六、数据目录说明

所有数据统一保存在 `/opt/WildAPI/`：

| 目录 | 内容 | 重要性 |
|-----|------|-------|
| `/opt/WildAPI/mysql` | MySQL 数据库文件 | ⭐⭐⭐ 核心数据 |
| `/opt/WildAPI/redis` | Redis 持久化文件 | ⭐⭐ 会话/限流缓存 |
| `/opt/WildAPI/backups` | 数据库备份（菜单 7 生成） | ⭐⭐⭐ 建议定期下载 |
| `/opt/WildAPI/logs` | 后端运行日志 | ⭐ 排障用 |
| `/opt/WildAPI/migrations` | 迁移脚本副本 | ⭐ 自动维护 |

**备份建议**：
- 每周在菜单执行一次 **7) 备份数据库**
- 宝塔 → 文件 → 下载 `/opt/WildAPI/backups/` 中最新的 .sql 文件到本地
- 或在宝塔 **计划任务** 中添加 Shell 脚本定时备份

## 七、常见问题

### Q1: 部署时提示端口被占用？
编辑 `.env`，把 `FRONTEND_PORT` 或 `BACKEND_PORT` 改成空闲端口，
回菜单选 **1** 重新部署即可。

### Q2: 前端打不开？
1. 菜单 **2** 查看容器状态，确认 4 个容器都是 Up
2. 宝塔 → 安全 → 放行你配置的前端端口（如 3002）
3. 云服务器还需在云控制台安全组放行该端口

### Q3: SSO 登录失败？
- 确认服务器能访问认证中心（默认直连同机 4000 端口）
- 菜单 **6** → 后端日志，查看具体错误提示

### Q4: 想更换域名 / 启用 HTTPS？
1. 宝塔 → 网站 → 添加站点并申请 SSL 证书
2. 站点反向代理到 `http://127.0.0.1:3002`（前端端口）
3. 修改 `.env` 的 `FRONTEND_URL` 为 `https://你的域名`，重启服务

### Q5: 如何更新到新版本的代码？
1. 菜单 **7** 先备份数据库
2. 上传新压缩包解压覆盖 `/opt/WildAPI/后端` 和 `/opt/WildAPI/前端`
   （`/opt/WildAPI/mysql` 等数据目录**不要动**）
3. 菜单 **1** 一键部署（自动执行增量迁移）

---

## 八、卸载

菜单选 **8**，按提示确认。数据目录会询问是否保留，建议先备份再删。

---

**部署完成！** 记住两个要点：
1. 日常操作只需 `./wildapi.sh` 一个命令
2. 数据都在 `/opt/WildAPI/`，备份好它就高枕无忧
